# `lola version`

Command reference, for lola users; back to [Using lola](../usage.md) and the [README](../../README.md).

```
lola version
```

Alias: `ver`; `lola --version` prints the same. Print lola's version.

JSON (`lola version --json`; `lola --version --json` too): `version`, and `go`, the Go version lola was built with.
Under `--plain` it prints both on one tab-separated row.
